# Sistema de Cadastro de Alunos em Java

Um sistema simples em Java para gerenciamento e cadastro de alunos via terminal, desenvolvido para prática de Programação Orientada a Objetos (POO), manipulação de coleções (`ArrayList`) e estruturas de controle.

---

## Funcionalidades

- **Cadastrar Aluno:** Permite inserir Nome, Matrícula e Curso de um novo aluno.
- **Listar Alunos:** Exibe todos os alunos cadastrados no sistema.
- **Buscar Aluno:** Pesquisa um aluno específico por meio da sua Matrícula.
- **Menu Interativo:** Interface via terminal fácil de usar e com validação de opções.

---
